# Chaos Button 🎛️💥

**DON'T PRESS THIS BUTTON** — every click unleashes unpredictable chaos.  
A fun, addictive, and slightly insane single-button website made with HTML, CSS, and JavaScript.

---

## 🔥 Features

- **Random chaos events** each click:
  - Funny sounds and voice effects
  - Floating emojis
  - Screen shake and rotation
  - Pop-up phrases like *"Are you proud of this?"*
  - Background color flashes
  - Cursor disappears or turns weird
  - Click counter to track your chaos level

- Totally **useless, but addictive** — you won’t be able to stop clicking.

---

## 🛠️ Technologies

- **HTML** – Structure
- **CSS** – Styling, animations, and visual effects
- **JavaScript** – Randomized chaos logic, audio, and emoji effects
- **Web APIs** – Web Audio API, Speech Synthesis API

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Make sure the main file is named `index.html`.
3. Open `index.html` in any modern browser (Chrome, Firefox, Edge).
4. Click the **DON'T PRESS THIS BUTTON** and enjoy the chaos!
